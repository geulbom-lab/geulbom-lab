### HTML 발표자 보기

**청중에게는 슬라이드를, 내 노트북에는 대본과 다음 장을.**  
HTML 파일 하나로 듀얼 모니터 발표를 준비하는 템플릿입니다. 발표자 화면에서 현재 장·다음 장·대본·배정 시간·타이머를 확인할 수 있습니다.

**발표자 화면** 버튼으로 별도 창을 열고, 모니터를 확장해 각 창을 옮기세요. 청중 화면은 **전체화면 버튼 또는 F 키**로 크게 띄울 수 있습니다.

예시 슬라이드 7장의 제목과 대본을 바꿔 내 발표로 사용할 수 있습니다. 파일을 내려받으면 오프라인에서도 실행되며, PDF 저장·인쇄를 지원합니다.

### 이 문화유산, 써도 되나요?

**“수업 자료에 넣어도 될까요? 편집해서 굿즈로 판매해도 될까요?”**  
문화유산 이미지를 찾고, 어디에 어떻게 사용할지에 맞춰 이용조건과 출처표시를 확인하도록 돕습니다.

찾는 이미지와 사용 목적 입력 → 이미지 선택 → 이용조건·출처 확인

**2026 모두의 AI 실험실 선정 · 시험 운영 중**  
과학기술정보통신부·한국지능정보사회진흥원(NIA) 지원으로 개발하고 있습니다.

이용조건을 확인하는 보조 도구입니다. 최종 사용 전 기관 원문과 권리 관계를 확인하세요.

### 예산과 작업기록

**예산은 얼마나 남았고, 어떤 일을 했는지 한곳에서 확인하세요.**  
프로젝트명과 예산을 입력하고 지출·증빙 위치·작업일지를 기록합니다. 지출 CSV와 전체 JSON 백업을 내려받거나 인쇄·PDF로 저장할 수 있습니다.

모두의 AI 실험실에서 사용하던 작업 흐름을 일반용으로 정리한 템플릿입니다. 기록은 사용하는 브라우저에 저장되므로 다른 기기로 옮기거나 브라우저 데이터를 지우기 전 JSON 백업을 내려받으세요.

참여자가 만든 비공식 도구이며, 증빙 파일 자체 저장·OCR·공식 제출서식 자동생성 기능은 포함하지 않습니다.
